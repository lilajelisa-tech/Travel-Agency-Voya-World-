 VoyaWorld - Travel Agency Website

VoyaWorld është një website për një agjenci udhëtimesh, i krijuar për të ofruar informacione mbi destinacionet dhe paketat turistike, si dhe mundësi për rezervime online.

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON

## Features

- Shfaqje e destinacioneve turistike
- Paketa udhëtimi
- Formular rezervimi
- Ruajtja e rezervimeve
- Kërkimi i rezervimeve
- Dërgimi i konfirmimeve me email
- Faqe kontakti

## Project Structure

- `index.html` – Faqja kryesore
- `booking.html` – Rezervimet
- `reservation.html` – Menaxhimi i rezervimeve
- `contact.html` – Faqja e kontaktit
- `style.css` – Dizajni i website-it
- `script.js` – Funksionalitetet JavaScript
- `server.js` – Backend me Node.js/Express
- `rezervimet.json` – Ruajtja e të dhënave të rezervimeve
